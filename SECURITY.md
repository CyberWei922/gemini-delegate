# Reporting security problems

Use GitHub's private vulnerability reporting for this repository when available.
Do not put credentials, private task inputs, personal settings or logs containing
those details into a public issue. If private reporting is unavailable, open an
issue asking for a private reporting channel without including the sensitive data.

This software is an execution helper, not an operating-system sandbox. It relies
on the official AGY account and the user's machine permissions. Read the source
before installing. Keep authentication local, restrict task scope and review all
edits. Never use permission bypasses as an installation workaround.
